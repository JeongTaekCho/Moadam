# 모아AI 답변 마크다운 서식 개선

- 작성일: 2026-10-13 (한국 시간)
- 상태: 코드 수정 완료 / 운영 확인 대기
- 영향 범위: RAG 답변 생성 지침, 모아AI 답변 및 스트리밍 표시

## 어떤 이슈였나

답변의 문단과 목록 구분이 부족하고 코드블록의 줄바꿈·들여쓰기가 제대로 표시되지 않아 읽기 어려웠다.

## 원인과 확인 근거

- `rag/app.py`의 생성 지침에 답변 문자열의 마크다운 작성 규칙이 없었다.
- `frontend/src/shared/ui/markdown.tsx`는 빈 줄로 먼저 분리하므로 코드블록 내부의 빈 줄을 보존하지 못했고, fenced 코드블록을 해석하지 않았다. 번호 목록도 `ul`로 표시했다.
- 작성 중인 답변은 마크다운 컴포넌트를 거치지 않고 텍스트로 표시했다.
- 목록 마커 스타일이 명시되지 않았고 코드블록용 스크롤·공백 보존 스타일이 없었다.

## 어떻게 수정했나

- JSON 응답 계약과 근거 검증 규칙을 유지하면서 `answer`에 문단 간 빈 줄, 자연스러운 띄어쓰기, 핵심 강조, 제목, 목록, 언어를 표시한 코드블록을 사용하도록 지침을 추가했다.
- 코드블록을 다른 블록보다 먼저 처리해 빈 줄·들여쓰기를 보존하고, 닫는 fence가 도착하지 않은 스트리밍 코드도 표시한다.
- 제목, 번호 목록, 글머리 목록, 인용문을 의미에 맞는 HTML 요소로 표시한다. 원시 HTML은 실행하지 않고 텍스트로 표시한다.
- 작성 중에도 동일한 마크다운 표시를 사용하며 아직 완성되지 않은 강조·인라인 코드 표시는 그대로 둔다.
- 본문·문단·목록 간격을 조정하고 긴 코드만 가로 스크롤하도록 했다.
- 기존 AI 오류/재시도 브라우저 검사에 마크다운 예시와 코드 공백 보존, HTML 비실행, 번호 마커, 모바일 가로 넘침 검증을 추가했다.
- RAG 전체 린트 중 발견한 기존 테스트 import 정렬 오류를 함께 정리했다.

## 검증 결과

- `pnpm check`, `pnpm build`: 통과.
- `pnpm test:ai-errors`: 1440px/390px 격리 브라우저 검사 통과. 제목·목록·강조·코드 공백 보존·HTML 비실행·코드 가로 스크롤을 확인하고 모바일 캡처를 확인했다.
- `pnpm test:performance`, `pnpm test:cache`, `pnpm test:chat-stream`: 통과.
- RAG Ruff check/format 및 unittest 21개: 통과.
- `make conventions`: 통과.
- 실제 유료 모델을 호출하지 않았으므로 운영 모델의 마크다운 지침 준수는 아직 확인하지 않았다.

## 운영 적용과 남은 작업

운영 배포는 수행하지 않았다. 프론트와 RAG 변경을 배포한 뒤 실제 답변의 띄어쓰기·문단·코드블록 품질을 확인해야 한다. 기존 저장 답변은 개선된 표시 방식으로 보이며 생성 지침은 새 답변에 적용된다.
