# 모임 최대 인원 설정

- 작성일: 2026-10-14 (한국 시간)
- 상태: 코드 수정 완료 / 운영 확인 대기
- 영향 범위: 모임 생성·설정, 초대 참여 API, 모임 조회 응답, groups 테이블

## 어떤 이슈였나

모임별 정원이 없어 생성·설정에서 최대 인원을 지정할 수 없었고 초대 참여 시에도 정원을 확인하지 않았다.

## 어떻게 수정했나

- 소유자를 포함한 최대 인원을 1~30명으로 설정한다. 기존 모임과 생성 시 생략한 정원은 30명이다. 기존 클라이언트가 수정 시 정원을 생략하면 기존 값을 유지한다.
- 생성과 소유자의 모임 설정에 같은 정원 컴포넌트를 사용한다. 주황색 채움 트랙, 숫자 입력, 키보드 조절, 현재 참여 인원 안내를 제공한다. 유효한 숫자와 슬라이더는 즉시 연동된다. 빈 입력·범위 밖 값은 입력을 마칠 때 허용 범위의 정수로 보정한다.
- 설정에서는 현재 참여 인원을 최솟값으로 표시한다. 서버도 최신 인원수를 확인하여 축소를 거절하며 현재 인원과 필요한 최소값을 안내한다.
- 참여와 설정 변경은 READ COMMITTED 트랜잭션에서 같은 groups 행을 FOR UPDATE로 잠근 뒤 인원을 조회한다. 서로 다른 초대 코드로 마지막 자리에 접근하더라도 직렬화한다. 기존 계정별 최대 3개 모임 제한을 유지한다.
- 정원이 찬 경우 HTTP 409와 안내 문구를 반환하며 초대 코드를 소모하지 않는다. 기존 멤버의 재참여는 정원과 무관하게 기존 모임을 반환한다.
- Group 응답에 max_members와 member_count를 추가하고 OpenAPI·프론트 타입을 재생성했다.
- 새 생성·초대 창을 열면 이전 설정 오류를 지우며, 모바일 메뉴를 닫고 편집 창을 연다.

## DB 변경과 운영 적용

1. Supabase SQL Editor에서 `supabase/migrations/20261014065425_group_capacity.sql` 전체를 실행한다. 운영 DB에는 아직 적용하지 않았다. 정식 migration 배포 흐름을 사용한다면 동일 migration을 그 흐름으로 적용하고 이력과 일치시킨다.
2. Render 백엔드를 새 코드로 배포한다.
3. Vercel 프론트엔드를 새 코드로 배포한다.
4. 생성 시 정원 저장 → 모임 설정 변경 → 정원에 도달한 모임의 초대 참여 차단을 운영에서 확인한다.

새 환경변수나 RAG 배포는 필요 없다. Flyway는 기본적으로 꺼져 있으므로 SQL이 자동 실행된다고 가정하지 않는다. 이미 Flyway로 DB를 관리하는 환경은 V7 migration으로 적용한다. 두 방식으로 별도 스키마를 만들지 않는다.

Migration은 기존 모임을 30명으로 설정하고 NOT NULL·1~30 CHECK 제약을 추가한다. 이미 30명을 넘는 모임이 있으면 인원을 삭제하는 대신 명시적으로 중단한다. 이 경우 해당 모임의 인원 정책을 먼저 정리해야 한다. 테이블 접근 권한·RLS는 변경하지 않는다.

## 검증 결과

- 백엔드: Maven verify 57개 테스트 통과. 기본 30명·선택 정원 저장, 1/30 경계와 범위 밖 값 검증, 정원 도달 시 초대 미소모 및 정원 확대 후 재참여, 잠금 후 인원 확인 순서, 현재 인원 이하 축소 차단, 생략 시 정원 유지, 기존 3개 모임 제한을 검증한다.
- DB: pnpm test:db. PGlite에서 migration 반복 적용, 기존 모임 30명 기본값, 1/30 허용, 0/음수/31/NULL 거절을 확인한다. 실제 Supabase 동시 요청 테스트는 수행하지 않았다.
- 프론트: pnpm check, pnpm build, pnpm test:groups-ui, pnpm test:performance. 1440px·390px에서 입력/슬라이더 연동, 방향키·End, 입력 보정, 생성·설정 저장 payload, 새로고침 유지, 인원 변경 오류와 정원 초과 메시지를 격리 API fixture로 검증한다. 화면 캡처로 레이아웃도 확인한다.
- make conventions: 계층·색상 토큰·migration 복사본 검사.

운영 배포와 실제 DB 적용 결과는 위 로컬 검증에 포함되지 않는다.
