# 모아담 페이지 일러스트·모션 개선

2026-10-08. 기존 주황색 디자인 토큰과 로고 캐릭터를 바탕으로 화면의 성격에 맞는 SVG 장면을 추가했다. 굵은 장식 제목·배지를 늘리지 않고 그림, 여백, 부드러운 색과 짧은 움직임으로 페이지의 차이를 표현했다.

## 참고한 레퍼런스와 적용 방향

| 레퍼런스                                                                            | 참고한 점                                          | 모아담 적용                                                       |
| ----------------------------------------------------------------------------------- | -------------------------------------------------- | ----------------------------------------------------------------- |
| [Headspace Illustration](https://live.standards.site/headspace/illustration)        | 따뜻한 색, 유기적인 형태, 단순하고 친근한 표현     | 주황·크림 중심의 곡선 배경과 작은 민트·라일락 포인트              |
| [Notion for Design](https://www.notion.com/en-gb/product/notion-for-design)         | 작업 공간 안에서 문서와 사람이 연결되는 구성       | 문서·대화·사람을 페이지별 작은 장면으로 표현                      |
| [Linear Features](https://linear.app/features)                                      | 제품의 데이터와 기능을 중심에 둔 구성              | 일러스트는 상단·빈 상태에 두고 목록·입력·주요 버튼의 영역을 유지  |
| [Atlassian Illustrations](https://atlassian.design/guidelines/brand/illustrations/) | 상황에 맞는 spot illustration, 빈 상태의 맥락 제공 | 자료·글·일정·내 활동의 빈 목록에 관련 그림 표시                   |
| [Atlassian Motion](https://atlassian.design/foundations/motion)                     | 명확하고 편안한 움직임, 접근성과 성능              | transform·opacity 기반의 짧은 진입, 미세한 호버, 동작 줄이기 지원 |

레퍼런스의 그림을 복제하거나 다운로드해서 사용하지 않았다. 일러스트는 저장소에서 직접 작성한 SVG이며, 브랜드 캐릭터는 기존 `moa-ai-icon.png`를 재사용한다.

## 페이지별 장면

| 화면        | 장면과 배치                                                                  |
| ----------- | ---------------------------------------------------------------------------- |
| 홈          | AI 안내 영역 오른쪽에 모아담 캐릭터와 문서가 모이는 장면                     |
| 자료 보관함 | 폴더와 문서, 작은 완료 표시                                                  |
| 커뮤니티    | 서로 겹치는 대화 말풍선과 공감 표시                                          |
| 일정        | 달력과 시계, 약속을 확인하는 표시                                            |
| 멤버·초대   | 서로 연결된 사람들과 초대 표시                                               |
| 마이페이지  | 프로필 카드와 체크, 내 기록에 맞는 빈 상태 그림                              |
| 모임 설정   | 설정 슬라이더와 보호 표시                                                    |
| 모아AI 모달 | 기존 캐릭터에 대화·문서의 작은 배경 장면. 제안 박스 3개는 다시 추가하지 않음 |
| 로그인      | 로고 캐릭터와 문서가 모이는 환영 장면                                        |

공통 컴포넌트는 [`PageIllustration`](../frontend/src/shared/ui/page-illustration.tsx), 스타일은 [`globals.css`](../frontend/app/globals.css)에 있다. `EmptyState`는 선택적인 `illustration` prop을 받는다.

## 움직임과 접근성

- 페이지 상단 진입: 320ms의 6px 이동과 fade.
- 주요 그림 진입: 460–600ms.
- 작은 종이·포인트: 4–5.8초 동안 아주 작게 움직이며 2–3회 후 멈춤.
- 주요 질문 버튼·내 활동 아이콘: 160ms 호버.
- `prefers-reduced-motion: reduce`일 때 새 애니메이션과 호버 이동을 끔.
- 장식 SVG는 `aria-hidden`, `focusable=false`, `pointer-events:none`을 사용하고 정보는 기존 제목·라벨로 전달.
- SVG는 자체 크기를 예약해 레이아웃 이동을 줄이고, 작은 화면에서는 그림 크기와 헤더 여백을 축소.
- 새 애니메이션 라이브러리나 외부 이미지 의존성을 추가하지 않음.

시각 검증은 실제 UI를 격리된 headless browser에서 렌더링하고, API만 가상 모임·프로필·자료로 대체해 진행한다. 실제 회원 데이터를 사용하거나 서버에 테스트 데이터를 저장하지 않는다. 이 시각 검증은 실제 DB·AI 연결 검증과 구분한다.

## 검증 결과

- 홈·자료·커뮤니티·일정·멤버·마이페이지·설정·모아AI·로그인: 데스크톱 1440px / 모바일 390px, 총 18개 화면 확인.
- 가로 넘침과 브라우저 런타임 오류 없음.
- 동작 줄이기 설정에서 새 일러스트 애니메이션 비활성화, 일반 설정에서 유한 반복 확인.
- TypeScript 검사 및 프로덕션 빌드 통과.
